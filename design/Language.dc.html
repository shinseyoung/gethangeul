What has to change in the code

01
Render the name Header.tsx already has currentLangName. Put it in the button. One line.
02
Detect, then remember Seed lang from navigator.language on first visit and persist it. Today it starts at 'ko' and forgets on every reload — on a site whose visitors are all foreign.
03
Load a face per script Thai and Vietnamese currently fall back to whatever the device has. Noto Sans Thai and a Vietnamese-covering body face, loaded only for those locales.
04
Language in the URL /en, /ko, /vi, /th plus a matching html lang and hreflang tags. Without it the dictionary's four translations collapse into one indexed page.
